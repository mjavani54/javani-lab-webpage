# Homepage manuscript update

This package updates the existing GitHub Pages/Jekyll site at mjavani54/javani-lab-webpage.

Replace these two files on the main branch:
- index.html
- assets/site.css

The remaining site files stay as they are. The homepage contains six recent-manuscript cards. Five venues are marked as potential; the LiH/linear H₄ manuscript is marked Submitted to Electronic Structure.

For a manual edit instead, insert recent-manuscripts.html immediately before the existing <section class="process"> in index.html, and append recent-manuscripts.css to assets/site.css. Do not add duplicate sections or CSS if you replace the full files.

After pushing to main, GitHub Pages will rebuild the site. Check the homepage at https://javani.org/.
