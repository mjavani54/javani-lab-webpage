Restore the missing Javani Research Lab website assets

Unzip this archive on your computer. In the GitHub repository mjavani54/javani-lab-webpage, open the existing assets folder, choose Add file > Upload files, and upload these THREE files from the extracted assets folder:

  hero-visual.webp
  mohammad-javani.webp
  site.js

Commit the upload to main. Keep the existing assets/site.css and all other repository files. Do not upload this ZIP as a single file, and do not replace the repository or the assets folder with only the ZIP contents.

The homepage refers to /assets/hero-visual.webp, the People page refers to /assets/mohammad-javani.webp, and the shared layout loads /assets/site.js. Once GitHub Pages rebuilds, check https://javani.org/ and https://javani.org/people/ and refresh the browser.
